Asks before the dangerous ones.

A Linux shell written in Rust. It reads each line before it runs. For the dangerous ones, it shows what would be touched and waits for you.

$curl -fsSL https://github.com/imshaid/oh-my-shell/releases/latest/download/install.sh | sh
Linux, x86_64 or aarch64, glibc 2.35 or newer

It asks first

Every line is read before it runs. The dangerous ones get a panel with what they would touch.

It stays offline

No network on the normal command path, and no telemetry.

AI is opt-in

Off until you run omsh ai setup. Nothing it suggests runs without a preview and your confirmation.

Young: a POSIX-compatible subset, and aarch64 was smoke-tested on a CI runner only. The limits
